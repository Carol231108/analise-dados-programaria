# Análise de Dados: Cenário Tech no Brasil (Data Hackers)

Este projeto foi desenvolvido durante o curso da **PrograMaria**, focado na análise exploratória e preditiva sobre o mercado de dados no Brasil.

## 📂 Conteúdo do Repositório
- **analise_dados.ipynb**: Limpeza, exploração e visualização dos dados da pesquisa Data Hackers.
- **regressao_linear.ipynb**: Aplicação de modelo de Machine Learning para identificar tendências e correlações.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python (Google Colab)
- **Bibliotecas:** Pandas, NumPy, Seaborn, Plotly e Scikit-Learn
- **Visualização Externa:** Dashboard no Looker Studio

## 🚀 Objetivo profissional
Este projeto demonstra minha capacidade de traduzir dados brutos em insights estratégicos, unindo minha formação em Administração com as competências técnicas de ADS.
